Serveur LanguageTool

Le serveur public (https://api.languagetool.org) est gratuit mais limité en nombre de requêtes. Pour un usage illimité et privé, héberge ton propre serveur (Docker, voir le dossier server/) et indique son adresse, par exemple http://100.x.y.z:8010 via Tailscale.

Compte LanguageTool Premium (facultatif)
Raccourci global

Sous Wayland, les applications ne peuvent pas intercepter de raccourci global. Associe cette commande à un raccourci dans ton bureau :

coquille --corriger
  • Hyprland : bind = CTRL ALT, space, exec, coquille --corriger
  • Sway : bindsym Ctrl+Alt+space exec coquille --corriger
  • KDE : Configuration › Clavier › Raccourcis › Ajouter une commande
  • GNOME : Paramètres › Clavier › Raccourcis personnalisés
Options
Bulle de correction en direct

La bulle apparaît dès qu'un champ contient au moins 3 mots ; un clic affiche les corrections, un clic sur une suggestion corrige directement le mot. Les champs de mot de passe et les barres d'adresse sont ignorés. Le texte des champs est envoyé au serveur LanguageTool configuré : préfère ton propre serveur pour la confidentialité.
